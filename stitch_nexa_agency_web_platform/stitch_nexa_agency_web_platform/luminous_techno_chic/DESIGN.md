## Brand & Style

This design system expresses a forward-looking creative and engineering convergence: high-velocity digital craftsmanship coupled with high-fashion technical polish. It marries the calculated precision of an advanced software studio with the tactile, iridescent, and buoyant energy of refined Y2K futurism. 

The aesthetic eschews overused, murky "AI glow" clichés in favor of curated specular reflections, liquid glass finishes, crystal-clear typography, and disciplined structural rhythm. The resulting interface feels luminous yet structured, energetic yet executive, and playful yet uncompromisingly robust.

Targeted at venture-backed founders, digital-native enterprise leaders, and design-led innovators, the system inspires confidence, creative audacity, and tactile delight through ambient back-illumination, translucent surfaces, and buoyant capsule geometry.

## Colors

The palette operates in a calibrated deep-space dark mode, letting chromatic luminosity lead visual hierarchy.

- **Base Obsidian Tech Canvas:**
  - `surface-canvas`: `#0A0914` (Deepest void base)
  - `surface-raised`: `#121024` (First-tier structured containers)
  - `surface-overlay`: `#1B1834` (Elevated modals, dynamic panels, interactive surfaces)
  - `surface-glass`: `rgba(27, 24, 52, 0.65)` (Backdrop-filtered layer)

- **Kinetic Gradient Spectrum:**
  - `primary`: `#C239D8` (Saturated Magenta-Purple)
  - `secondary`: `#99D4FF` (Specular Baby Blue)
  - `accent-violet`: `#7A5AF8` (Electric Bridge Violet)
  - Primary Linear Dynamic: `linear-gradient(135deg, #C239D8 0%, #7A5AF8 50%, #99D4FF 100%)`
  - Specular Sheen Highlight: `linear-gradient(180deg, rgba(255, 255, 255, 0.35) 0%, rgba(255, 255, 255, 0) 100%)`

- **Text & Contrast Hierarchy:**
  - `text-primary`: `#FFFFFF` (100% optical pure white)
  - `text-secondary`: `#B8B4D4` (Luminous tinted lavender gray)
  - `text-muted`: `#736E93` (Deep legible tech tone)

- **Iridescent Borders & Accents:**
  - `border-subtle`: `rgba(255, 255, 255, 0.08)`
  - `border-glass-specular`: `linear-gradient(135deg, rgba(255, 255, 255, 0.22) 0%, rgba(194, 57, 216, 0.15) 50%, rgba(153, 212, 255, 0.22) 100%)`

## Typography

The typographic tension pairs the brutalist precision of `Space Grotesk` with the hyper-legible neutrality of `Inter`, punctuated by uppercase `Space Mono` metadata tags.

- **Headlines (`Space Grotesk`):** Deliver modern tech presence. Tight letter-spacing (`-0.03em` to `-0.04em`) prevents display styles from drifting, retaining a sculptural silhouette.
- **Body Text (`Inter`):** Renders all continuous interface copy, descriptions, and technical specifications, maintaining absolute legibility against dark obsidian surfaces.
- **Labels & Micro-Tags (`Space Mono`):** Applied exclusively in uppercase with extended tracking (`0.14em`). Designed for version indicators, section coordinates, status chips, and code metrics, grounding the fluid aesthetics with retro-futuristic data rigor.

## Layout & Spacing

A 12-column fluid grid system anchors large-scale screens, resolving into a 6-column system on tablets and a single-to-dual column configuration on mobile. 

- **Outer Margins:** Scale from `3rem` (`48px`) on desktop viewports down to `1.25rem` (`20px`) on mobile viewports.
- **Gutters:** Standardized at `1.5rem` (`24px`) across desktop arrays, compressing to `1rem` (`16px`) beneath `768px`.
- **Rhythm Model:** Layout follows an 8pt base grid for macro-spacing and a 4pt sub-grid for dense micro-components. Modular cards leverage generous internal padding (`space-lg` to `space-xl`) to preserve breathing space around high-density gradient elements.

## Elevation & Depth

Depth is defined via luminous atmosphere and physical glass dispersion rather than standard drop shadows:

1. **Backdrop Glassmorphism:** Semi-transparent containers (`rgba(27, 24, 52, 0.65)`) utilize hardware-accelerated background blur (`backdrop-filter: blur(20px) saturate(180%)`).
2. **Specular Rim Lighting:** Border treatments rely on subtle 1px directional gradient masks that simulate top-down studio edge lighting (`#FFFFFF` down to transparent obsidian), creating a crisp physical bevel.
3. **Ambient Chromatic Glow:** Elevated cards and interactive states radiate soft, hyper-diffused photonic halos:
   - Floating Card: `0 12px 36px -6px rgba(10, 9, 20, 0.8), 0 0 24px -2px rgba(194, 57, 216, 0.12)`
   - Active Interactive Glow: `0 0 28px rgba(153, 212, 255, 0.35), 0 0 12px rgba(194, 57, 216, 0.2)`
4. **Surface Tiers:** Content layers ascend from `surface-canvas` (`#0A0914`), to structured `surface-raised` (`#121024`), to active/floating `surface-overlay` (`#1B1834`).

## Shapes

The design system embraces buoyant, hyper-tactile pill curves combined with structural geometric framing:

- **Bubble-Pill Scale (`3`):** Action targets, badges, search pills, and active status tags use full-radius pill styling (`border-radius: 9999px`).
- **Modular Containers:** Cards, modal viewports, and deep-tech panels feature pronounced soft edges (`border-radius: 1.5rem` to `2rem`).
- **Inner Nested Harmony:** Child elements preserve geometric alignment through proportional radius nesting: an outer card at `1.5rem` (`24px`) contains internal controls with `0.75rem` (`12px`) to `1rem` (`16px`) radii, maintaining uniform optical channels.

## Components

### Buttons
- **Primary Kinetic Glow Button:** Fully pill-shaped (`rounded-full`). Background is a vibrant linear gradient from `#C239D8` through `#7A5AF8` to `#99D4FF`. Displays a subtle interior top-edge specular line (`inset 0 1px 1px rgba(255, 255, 255, 0.5)`). Typography uses `Space Grotesk` Medium in pure white. Hover state scales slightly (`transform: scale(1.02)`) accompanied by an amplified diffuse cyan-magenta glow.
- **Glass Secondary Button:** `surface-raised` background with `backdrop-filter: blur(12px)`. Outlined with a 1px specular gradient border. Text is `text-primary`. Hover state triggers background fill to `surface-overlay` with a softened violet glow.

### Badges & Status Chips
- Pill geometry with `label-mono` typography. Composed of an ultra-thin 1px border (`rgba(153, 212, 255, 0.25)`), a faint tinted background (`rgba(153, 212, 255, 0.08)`), and an optional glowing 6px circular dot indicator featuring a pulsating chromatic animation.

### Modular Cards
- Structural bases with `rounded-2xl` (`1.5rem`) to `rounded-3xl` (`2rem`) perimeters. Structured with `surface-raised` or frosted `surface-glass`. Features a 1px iridescent gradient border (`border-glass-specular`). Content sits across clear spatial bands with metadata placed in top pill capsules.

### Input Fields
- Deep tech rounded pill containers (`border-radius: 9999px`) or soft capsule frames (`border-radius: 1rem`). Fill color uses `surface-canvas` with a `1px` subtle rim border (`rgba(255, 255, 255, 0.1)`). Placeholder text uses `text-muted`. Focus states trigger an iridescent gradient border stroke and an outer `0 0 0 3px rgba(153, 212, 255, 0.2)` baby blue focus ring.

### Checkboxes & Radio Buttons
- Checkboxes feature `rounded-md` (`6px`) corners; radio buttons are fully circular. Default state is a translucent dark obsidian well. Checked state fills with the core magenta-to-baby-blue gradient and a centered white icon, accented by a soft outer neon bloom.

### Lists & Navigation Rails
- Clean, decoupled rows separated by faint dividers (`rgba(255, 255, 255, 0.05)`). Interactive rows utilize subtle liquid-glass hover pills with smooth cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`).
